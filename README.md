# Charm the Commuter: Forecast a City That Isn't

One weather forecast line for a city that does not exist — Brindlewick — written to make a bored commuter smile.

## Entry

> Brindlewick: 19°C, confetti drizzle, buses on time for once — bring an umbrella, leave the grudge at home.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```

Writes exactly one line (≤ 140 characters) to `entry.txt` in the output directory.
